### Commands:

- `/delivery group create <name>` - Creates a new group
- `/delivery group add <player>` - Adds a player to the group
- `/delivery group leave` - (Member Only) Leaves the group
- `/delivery group remove <player>` - (Owner Only) Removes a player from the group
- `/delivery group info` - Displays information about the group
- `/delivery debug addmoney <amount>` - Adds money to the group
- `/delivery debug addxp <amount>` - Adds experience to the group
- `/delivery task available` - Displays available tasks
- `/delivery task accept <taskid>` - Accepts a task
- `/delivery task info <taskid>` - Displays information about a task
- `/delivery task submit <taskid>` - Submits a task for review and completion
